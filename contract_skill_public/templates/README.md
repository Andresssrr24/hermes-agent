# Templates Directory

This public-safe copy does not include production PDF templates.

For a private deployment, place approved contract templates here or update `references/plans.json` to point to the correct template paths.

The default sample plan configuration expects these filenames:

- `650.pdf`
- `1500.pdf`
- `2500.pdf`

Do not commit templates that contain real client data, real company identifiers, private contract terms, signatures, tax IDs, identity documents, phone numbers, or email addresses.
